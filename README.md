# TropiCare

> **AI-guided symptom checker for early tropical disease risk assessment, personalized healthcare guidance, and faster access to medical support.**

TropiCare is an AI-powered health assessment platform designed to help patients and clinicians identify tropical disease risks faster through adaptive symptom questioning, machine learning prediction, risk stratification, personalized recommendations, and nearby healthcare access.

🌐 **Live Application:** [TropiCare](https://tropi-care.vercel.app/)

# Overview

TropiCare bridges the gap between symptom onset and clinical attention in resource-constrained settings.

By combining machine learning with adaptive questioning, it provides structured, risk-based guidance to patients and frontline healthcare workers before a doctor is available.

The platform is built around:

- **22 diseases covered**
- **76 tracked symptoms**
- **15 maximum assessment questions**
- **3 machine learning models**

---

# AI-Powered Assessment System

## Adaptive Symptom Assessment

TropiCare dynamically adjusts questions based on user responses to create a faster and more relevant assessment experience.

- Reduces unnecessary questions
- Improves assessment efficiency
- Adapts based on symptom patterns

---

## Machine Learning Disease Prediction

The prediction engine uses an ensemble machine learning approach combining:

- Random Forest
- XGBoost
- Logistic Regression

The models analyze symptom patterns to estimate potential disease risks across tropical and common illnesses.

---

## Risk Stratification

Each assessment result is classified into:

- **Low Risk**
- **Medium Risk**
- **High Risk**

Users receive clear next-step guidance based on their risk category.

---

## AI-Powered Recommendations

TropiCare generates personalized recommendations based on assessment results, including:

- Home care guidance
- Suggested medical tests
- When to seek professional healthcare

---

## Assessment History

Users can securely access previous assessment results to track changes over time and support better healthcare discussions.

# Built for West Africa

In many parts of West Africa, the time between experiencing symptoms and accessing clinical support can take days rather than hours.

TropiCare is designed to help reduce this gap by providing early risk assessment and actionable guidance for conditions where timely attention can significantly improve outcomes.

The platform focuses on healthcare challenges within tropical regions while supporting—not replacing—professional medical diagnosis.

---

# Disclaimer

TropiCare is an informational health support tool and does not replace clinical examination or professional medical advice.

Always consult a qualified healthcare professional for diagnosis and treatment decisions.
